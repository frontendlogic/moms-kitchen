# 🍴 Moms Kitchen

Moms Kitchen is a modern Django-based food and recipe website designed for food lovers. The platform allows users to explore recipes from different cuisines, discover cooking ideas, and enjoy a visually appealing food experience.

## ✨ Features

* User Registration and Login
* Recipe Upload and Management
* AI Recipe Generator
* Recipe Categories

  * Indian
  * Chinese
  * Italian
  * Japanese
  * Korean
  * Thai
* User Dashboard
* Password Reset Functionality
* Responsive Design
* Feedback System
* Reward Claim Feature

## 🛠 Technologies Used

* Python
* Django
* HTML5
* CSS3
* JavaScript
* SQLite3

## 📁 Project Structure

* templates/ – HTML templates
* static/ – CSS, JavaScript, and Images
* migrations/ – Database migrations
* manage.py – Django project management

## 🚀 Installation

1. Clone the repository

git clone https://github.com/frontendlogic/moms-kitchen.git

2. Navigate to the project folder

cd moms-kitchen

3. Install dependencies

pip install django

4. Apply migrations

python manage.py migrate

5. Run the development server

python manage.py runserver

6. Open in browser

http://127.0.0.1:8000/
